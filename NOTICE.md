# Notice

The MIT license in `LICENSE` covers the parts of this repository that were
written for it: the odds engine, the tools, the tests, the site, and the
hand-assigned ratings in `data/ratings.psv`.

It does **not** cover everything shipped here. Three things arrive under their
own terms.

## Game art — `assets/sprites/`, `assets/room-frame.png`, `assets/room-floor.png`

Not covered by this project's license.

The item sprites and the room texture are artwork from *The Binding of Isaac*,
which belongs to its authors and publisher. They are included so a fan tool can
show you which item it is talking about and look like it belongs to the game.
This project is unofficial and is **not affiliated with, endorsed by, or
sponsored by** Edmund McMillen, Nicalis, or anyone else involved in the game.

`room-frame.png` is a supplied room texture, used as a CSS `border-image` so the
stonework renders at its own resolution rather than being upscaled to fill a
wide viewport. `room-floor.png` is a mirrored tile taken from that room's
interior.

The sprites are genuinely optional. Every one is generated by
`tools/build-sprites.py` from a sprite pack that is not committed here, the site
degrades gracefully when the folder is absent, and a test asserts only that a
*record* exists for each item — not that art does. To remove them:

```
rm -rf assets/sprites && node tools/build-items.mjs
```

The page keeps working; it just loses the pictures. Removing the room art is a
CSS change rather than a deletion — `--floor` already carries the floor colour,
so dropping the two `url()` references in `assets/style.css` leaves a flat
background and no broken layout.

If you represent a rights holder and would prefer the art not be distributed
here, open an issue and it will be removed.

## Typeface — `assets/fonts/`

Silkscreen by Jason Kottke, under the SIL Open Font License 1.1. The full
license text ships alongside the font as `assets/fonts/Silkscreen-OFL.txt`, as
the OFL requires. It is redistributed here, not relicensed.

## Game data — `data/scraped.json`

Not committed, and deliberately so. It is derived from `items.xml` and
`itempools.xml` inside a *Binding of Isaac* installation, which belongs to the
game's authors. `tools/scrape.mjs` generates it locally from a copy you already
own. Nothing scraped from the game files is redistributed by this repository.

## What is actually ours to give away

The five-axis rating model, the composition rules, the calibration solver, the
boss weight vectors, and the 181 hand-assigned rating vectors. Those are MIT,
and arguing with them is the point — see `CONTRIBUTING.md`.
